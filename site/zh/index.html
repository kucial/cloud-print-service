自托管打印网关

业务系统与仓库里每一台打印机之间，只需一套 API。

ERP 或 WMS 只需提交标签、小票或 PDF，并附上自己的单据号。云打印服务负责把它转换成打印机能识别的语言，保证只打印一次，并实时告诉你哪些打印机现在可用。支持 Zebra 标签机、小票机和办公打印机，网络连接或 USB 连接均可。

5 分钟完成部署 在 GitHub 上查看
  • 一个 Go 程序 + 一个 JSON 配置
  • 无需数据库服务（内置 SQLite）
  • 自带运维面板
  • 同一张标签绝不重复打印

适用场景

打印什么由业务系统决定；打印到哪里、怎么打印、到底有没有打出来，交给云打印服务。

WMS 打印快递面单

把 ZPL（或 PDF/PNG）发到任意兼容 Zebra 的标签机。每个任务都带上订单号或包裹号，超时重发、系统重试都不会多打一张。

zebra9100 · ZPL

前台打印小票

在 Epson TM、芯烨（Xprinter）等 58/80 mm 小票机上打印 ESC/POS 小票。缺纸、开盖等状态会实时反馈。

escpos9100 · ESC/POS

发票与装箱单

把 PDF、PNG 或 JPEG 发到办公激光或喷墨打印机。服务会按打印机的能力转换格式：IPP、PCL/PostScript，或 Epson 墨仓式喷墨用的 ESC/P-R，页面有颜色时按彩色打印。

ipp · pdl9100 · escpr9100

打包电脑上的 USB 打印机

打印机插在 Windows/Linux 电脑上，或插在华硕路由器、AiMesh 节点上，在那台设备上运行 cps-agent，它就会像网络打印机一样加入设备列表。原厂驱动无需卸载。

cps-agent · USB

全部打印机一目了然

一次调用即可拿到每台打印机的状态、纸张与碳带、排队数量，以及一个直观的 usable（是否可用）。/ui/ 运维面板实时显示同样的信息，还能管理任务、令牌，预览 ZPL。

GET /api/v1/printers/status

打印机未到，先完成对接

vprint 是一台虚拟打印机，在真实端口上说真实的 ZPL、ESC/POS、IPP 或 PJL。每张标签都会渲染成 PNG，还能模拟缺纸、离线、打印中途断开等故障。

vprint · 测试替身

整体架构

仓库局域网内部署一台服务器。网络打印机由服务器直接连接；USB 打印机通过它所连接设备上的小型代理程序接入。

一个打印任务的生命周期

提交调用 POST /api/v1/jobs 并带上 external_id。同一个单据号再次提交，返回的仍是原来那个任务。
排队每台打印机有自己的队列，服务重启也不会丢。打印机不可用（usable 为否）时任务会暂存等待，不会丢失。
发送需要时先转换格式，再把数据写入打印机，只写一次。数据一旦发出，服务绝不会自行重发。
结果 printed 打印机确认已打印 sent_unknown 已发出但未获确认，由人工判断，杜绝重复打印 failed 未打印，并附上原因

快速部署

适用于与打印机处在同一局域网的 Linux 服务器。需要 Docker，或用 Go 1.26 以上版本从源码构建。大约五分钟。

  1. 编写配置

    用 openssl rand -hex 24 生成管理员密钥，并填入网络打印机。其余配置项都有可用的默认值。

    // config.json
{
  "addr": ":8080",
  "api_keys": {
    "粘贴你的管理员密钥": { "client_id": "ops", "role": "admin" }
  },
  "printers": [
    { "printer_id": "wh1-pack-01", "name": "1 号打包台", "site": "wh1",
      "driver": "zebra9100", "host": "192.168.10.21", "port": 9100, "enabled": true }
  ],
  "discovery": { "enabled": true, "site": "wh1" }
}

  2. 启动服务端

    一个容器就够了。数据卷保存任务、令牌和代理凭证。--network host 让自动发现能收到打印机的 mDNS 广播；不需要自动发现时，用 -p 8080:8080 即可。

    git clone https://github.com/kucial/cloud-print-service.git
cd cloud-print-service
docker build -f server/Dockerfile -t cps .
chmod 644 config.json
docker run -d --name cps --restart unless-stopped --network host \
  -v "$PWD/config.json:/etc/cps/config.json:ro" \
  -v cps-data:/var/lib/cps \
  cps
    不用 Docker：直接编译程序 
    go build -o cps    ./server/cmd/cps
go build -o cpsctl ./server/cmd/cpsctl
sudo apt install poppler-utils fonts-liberation fonts-wqy-zenhei   # PDF 转换所需
./cps -config config.json

    systemd 服务、Caddy/nginx 反向代理 HTTPS 等内容见安装指南。

  3. 检查运行状态

    打开 http://<服务器>:8080/ui/，用管理员密钥登录。自动发现的打印机会出现在 Discovery 页，确认后即可纳管。命令行检查：

    curl http://<服务器>:8080/healthz                       # 200 OK
# 镜像里自带管理命令行，后续步骤都使用这个别名
alias cpsctl='docker exec -e CPSCTL_URL=http://127.0.0.1:8080 -e CPSCTL_ADMIN_KEY=<管理员密钥> cps cpsctl'
cpsctl printers                                         # 每台打印机是否可用，不可用的原因

  4. 为业务系统签发令牌

    每个系统一个独立令牌。令牌只显示一次，服务端只保存其哈希，可随时轮换或吊销。

    cpsctl token issue --client-id wms --ttl 365d

  5. 打印

    ZPL 可以直接以文本提交，其他格式用 base64 提交。external_id 填你自己的单据号。

    curl -X POST http://<服务器>:8080/api/v1/jobs \
  -H "Authorization: Bearer $WMS_TOKEN" -H "Content-Type: application/json" \
  -d '{"printer_id":"wh1-pack-01","external_id":"SO-10042-label",
       "zpl":"^XA^FO50,50^A0N,50,50^FDHello CPS^FS^XZ"}'

# 把 PDF 发到办公打印机：打印机不支持 PDF 时由服务自动转换
curl -X POST http://<服务器>:8080/api/v1/jobs \
  -H "Authorization: Bearer $WMS_TOKEN" -H "Content-Type: application/json" \
  -d '{"printer_id":"hq-office-01","external_id":"INV-2026-0042","format":"pdf",
       "payload_base64":"'"$(base64 < invoice.pdf | tr -d '\n')"'"}'

curl -H "Authorization: Bearer $WMS_TOKEN" http://<服务器>:8080/api/v1/jobs/<job_id>

    完整 API 文档可在你的服务器上访问 http://<服务器>:8080/docs/ 查看。

  6. 接入 USB 打印机（可选）

    先在服务端生成一次性注册令牌，再在连着打印机的电脑或路由器上启动代理。约 30 秒后，打印机就会出现在面板里。

    cpsctl agent enroll --id pc7 --site wh1 --ttl 24h

    从发布页获取 cps-agent。Windows 上可以运行桌面版 cps-agent-gui.exe（填入服务器地址和令牌），也可以安装为系统服务：

    :: Windows，以管理员身份打开命令提示符
set CPS_AGENT_SERVER=http://<服务器>:8080
cps-agent.exe -enroll <令牌> -id pc7 -site wh1 -install

# Linux
CPS_AGENT_SERVER=http://<服务器>:8080 cps-agent -enroll <令牌> -id pc7 -site wh1 \
  -config /etc/cps-agent/agent.json

    华硕路由器 / AiMesh 节点：使用 koolshare 软件中心插件，或通过 SSH 安装 /jffs 软件包。各平台的详细步骤见安装指南。

手头还没有打印机？运行 go run ./vprint/cmd/vprint -count 2 -id wh1-pack -render，再用 server/config.example.json 启动服务端。打印出的标签会以图片形式显示在 http://localhost:19200。

支持的打印机

driver 决定服务如何与打印机通信。所有打印机都可以接收 PDF、PNG 和 JPEG，打印机不能直接打印时由服务自动转换。

打印机driver状态来源可直接打印
Zebra 及兼容 ZPL 的标签机zebra9100状态查询指令，含纸张与碳带ZPL
ESC/POS 小票机（Epson TM、芯烨等）escpos9100实时状态ESC/POS
支持 IPP 的办公打印机（多数网络激光/喷墨机）ipp打印机状态及该任务自身的记录以打印机上报为准（PDF、JPEG、URF…）
JetDirect 办公打印机pdl9100PJLPCL、PostScript
不支持 IPP 的 Epson 喷墨机（墨仓式 L 系列）escpr9100仅能检测是否在线ESC/P-R，彩色，A4
以上任意一种的 USB 版本经 cps-agent同上，按 USB 设备 ID 自动识别同上

不支持：只能依靠厂商电脑驱动工作的“主机型”打印机，例如佳能 CAPT 激光机（LBP 系列）和部分低端 GDI 机型。选购时请确认规格表里有 IPP/AirPrint、PCL 或 PostScript。各类打印机的验证情况见 STATUS.md。
