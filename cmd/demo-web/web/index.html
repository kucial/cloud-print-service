Outbound orders

What this demonstrates

  • Stable external_id per order line — retries cannot duplicate labels.
  • Retry only on 503 queue_full and transport errors; never on 4xx.
  • A job reported sent_unknown is never retried automatically.
  • Status comes from the API (SSE, polling as fallback), never from the 202.
  • Dispatch uses a client token; the admin token is optional and only previews.
  • ZPL payloads are never logged — only ids and byte counts.
